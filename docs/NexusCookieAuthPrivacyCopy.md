# Nexus Mods Browser Cookie Auth Privacy Copy

Status: draft for legal/compliance review before release.

## Modal Title

Use browser sign-in for Nexus Mods downloads?

## Body Copy

BohemiX can read your local browser session Cookie for nexusmods.com when no API key is available or a direct download needs browser authentication.

Reads only Nexus Mods session cookies from Chrome, Edge, Firefox, then Brave, stopping at the first valid session.

Cookies stay on this device, are never logged or saved, are attached only to *.nexusmods.com requests, and are erased from memory after each request.

Revoke from Settings > Mods, sign out of Nexus Mods in your browser, or use an API key instead.

Draft privacy copy: legal/compliance review required before release.

## Controls

- Agree
- Decline
- Do not ask again

## Decline Path

If declined, BohemiX does not read browser cookies and continues to guide the user toward OAuth or a manual Nexus Mods API key.
